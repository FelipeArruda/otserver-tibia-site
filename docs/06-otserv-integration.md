# 06 — Integração com OTServ

## Objetivo
Conectar o painel ao servidor para:
- verificar disponibilidade;
- mostrar players online;
- carregar personagens, itens e monstros;
- adaptar comportamento por versão.

## Adapter pattern
Exemplos:
- TFS14Adapter
- CanaryAdapter
- OTXAdapter
- CustomAdapter
