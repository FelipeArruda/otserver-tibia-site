# 01 — Visão do Produto

## Objetivo do produto
Criar um painel web para administração e exposição de dados de servidores OTServ/Tibia, com experiência inspirada em portais como o MyAAC, porém com arquitetura moderna, extensível e preparada para múltiplos servidores.

## Público-alvo
- administradores de OTServ;
- equipes de desenvolvimento;
- designers de temas;
- jogadores do servidor.

## Objetivos do MVP
- autenticação;
- cadastro de servidor;
- status online/offline;
- quantidade de players online;
- leitura de personagens;
- base para temas;
- base para shopping.
